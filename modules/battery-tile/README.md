# Battery Tile

Battery level, charging status, a progress indicator and a Refresh button. No state or timer is needed.

Minimum compatible Core: HyprDroid v0.7.1 with official Plugin API v2 packages enabled.

Permissions: ui.tile, system.battery.

Install with `hypr install battery-tile` and add with `hypr tile add battery-tile`.

Run `lua5.4 tools/test-v2-demos.lua` from the repository root.
