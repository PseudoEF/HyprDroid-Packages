# Clock Tile

Current time and date, a 12/24-hour switch and a foreground timer. Each tile stores its own format.

Minimum compatible Core: HyprDroid v0.7.1 with official Plugin API v2 packages enabled.

Permissions: ui.tile, system.time, state.local.

Install with `hypr install clock-tile` and add with `hypr tile add clock-tile`.

Run `lua5.4 tools/test-v2-demos.lua` from the repository root.
